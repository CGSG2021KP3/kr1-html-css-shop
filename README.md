## Описание проекта

Многостраничный сайт турагентства «Перевал», которое продаёт туры по России в небольших группах: Алтай, Байкал, Карелия, Камчатка, Дагестан, Хибины, Куршская коса, Териберка. Пользователь может посмотреть каталог, открыть страницу тура с программой и тарифами, оставить заявку на бронирование или задать вопрос.

Сайт сделан на чистом HTML и CSS, без фреймворков и без JavaScript. Модальное окно, раскрывающиеся вопросы FAQ и мобильная раскладка работают средствами HTML и CSS.

## Структура проекта

```
kr1-html-css-shop/
├── index.html      — главная
├── catalog.html    — каталог туров
├── product.html    — страница тура (Алтай)

├── success.html    — страница «Заявка отправлена» (доработка)
```

Папки `js/` в проекте нет: модальное окно реализовано на CSS через псевдокласс `:target`, поэтому скрипт не понадобился.

## Используемые технологии

- HTML5: семантические теги, формы со встроенной валидацией, `details`/`summary`, таблицы.
- CSS3: переменные, Flexbox, CSS Grid, позиционирование, псевдоклассы `:hover`, `:focus-visible`, `:target`, `:disabled`, `:user-invalid`, CSS-счётчики, медиазапросы.
- Методология БЭМ для именования классов.
- Шрифты Unbounded и Manrope (Google Fonts) с системными запасными шрифтами.
- Git и GitHub Pages.

## Самостоятельные доработки

1. **Собственная визуальная концепция.** Палитра хвойного, мха и охры отсылает к туристической маркировке троп: полоски маркировки стали знаком логотипа. Hero-блок оформлен как топографическая карта с маршрутом. Иллюстрации направлений нарисованы в SVG.
2. **Дополнительные страницы.** `success.html` завершает сценарий заявки: все формы отправляются на неё. `404.html` показывается GitHub Pages при неверном адресе.
3. **Расширенный каталог.** 8 туров, категории, фильтры по длительности, сложности и сезону, сортировка. Блок фильтров «прилипает» при прокрутке.
4. **Карточки с модификаторами.** Отдельный блок `badge` с модификаторами `--new`, `--sale`, `--muted`; модификатор `tour-card--soldout` для туров без мест (серое фото и неактивная кнопка). Старая цена при скидке.
5. **Подробная страница тура.** Программа по дням, блок «Входит / оплачивается отдельно», FAQ на `details`/`summary` без JS, ближайшие даты с количеством мест.
6. **Доработанные формы.** Группировка полей через `fieldset`/`legend`, подсказка к телефону через `aria-describedby`, недоступный тариф через `disabled`, подсветка ошибок через `:user-invalid` только после ввода, кнопка очистки формы.
7. **Блоки главной.** Шаги бронирования с номерами через CSS-счётчики, отзывы, призыв к действию.
8. **Доступность.** Видимый фокус у всех интерактивных элементов, `aria-current` у активного пункта меню и в крошках, `aria-label` у кнопки «Наверх» и крестика модалки, альтернативный текст у изображений, учёт `prefers-reduced-motion`.
9. **Базовая адаптивность.** Раскладки перестраиваются в одну колонку на узких экранах (полная адаптация — в КР №3).
